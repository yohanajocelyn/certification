ReportService
in package

ReportService.php : 18

Garage rental reports: per month of a year, per day of a month, per garage type and per tenant.

Rentals count in the period of their start date, extensions in the period they were made. The period's rows are loaded with Eloquent date scopes and grouped in PHP (no raw SQL).
