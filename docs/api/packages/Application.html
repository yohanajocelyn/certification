Classes

RentalNotExtendableException
Thrown when an admin tries to extend a rental that does not cover today.
TenantAlreadyDecidedException
Thrown when an admin tries to accept or reject a registration that was already decided.
GarageController
Admin pages to list garages and create them in batches per type.
RentalController
Admin list of garages rented today, the starting point for extending a rental.
RentalExtensionController
Admin extension of a running rental in two steps: choose the new end date, then check the remaining cost (whole months + leftover days) and upload the payment proof.
ReportController
Garage rental report pages: per month of a year, per day of a month, per garage type and per tenant. Validates the filters; ReportService does the counting.
TenantController
Admin pages to review tenant registrations and accept or reject them after checking the KTP.
AuthController
Logs users in and out. Only approved accounts may log in.
RegisterController
Registers new tenants. They stay pending until an admin verifies their KTP.
Controller
HomeController
Landing route after login: sends each role to its starting page.
RentalController
Tenant pages: my rentals, and renting a garage in two steps (1. vehicle and dates, 2. garage, total and payment proof).
VehicleController
Tenant page listing their own vehicles. Vehicles are registered while renting and never edited.
EnsureUserHasRole
Lets a request through only when the logged-in user has the given role (route alias: role).
Garage
A rentable garage with a type-prefixed code such as S001, C010 or E002.
Rental
One vehicle parked in one garage for a period. Dates are inclusive: the rental covers every day from start_date up to and including end_date.
RentalExtension
An admin moving a rental's end date later, with its extra cost and payment proof.
User
An account: either an admin or a tenant who rents garages.
Vehicle
Parent of every vehicle a tenant can park. All types share the `vehicles` table (single-table inheritance on `type`); each child class holds the parking rules of its type. Vehicles are never edited, so rentals reference them directly.
Bicycle
A bicycle: no plate, parks only in a bike garage.
Car
A petrol car: needs a plate, parks only in a car garage.
ElectricCar
An electric car: needs a plate and a battery capacity, parks in a car or an electric garage, and is charged to full in an electric garage.
Motorcycle
A motorcycle: needs a plate, parks only in a bike garage.
AppServiceProvider
Registers app-wide settings.
GarageService
Garage use cases: listing and batch creation with sequential codes. Prices never change after creation.
RentalService
Rental use cases: a tenant's rentals, quoting and booking a garage, and an admin extending a running rental. Conflicts tied to a form field are thrown as ValidationException so the message appears under that field.
ReportService
Garage rental reports: per month of a year, per day of a month, per garage type and per tenant.
TenantService
Tenant use cases: registration and the admin's verification (accept or reject, once).
VehicleService
Vehicle use cases for tenants. Vehicles are registered while renting and never edited.
